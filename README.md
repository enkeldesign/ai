# ai

This repository is configured to work alongside the [enkeldesign/webb](https://github.com/enkeldesign/webb) project.

## Connecting to the `webb` repository

If you would like to connect this repository to the public `webb` project as an additional remote, run:

```bash
git remote add webb https://github.com/enkeldesign/webb.git
```

You can then fetch the remote branches as needed:

```bash
git fetch webb
```

These commands link your local clone of this repository to the upstream `webb` repository without modifying the version-controlled files here.
