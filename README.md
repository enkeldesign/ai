# Revelation AI

A hard-SF / techno-theological novel project set in 2027.

The story mirrors the structure and symbolic logic of the Book of Revelation while grounding each event in plausible AI, climate, infrastructure, persuasion, and social-system mechanisms.

## Canon and project instructions

- `AGENTS.md` — repository-level operating contract for the writing team.
- `docs/premise.md` — fixed author canon.
- `docs/decisions-log.md` — explicit author-approved creative/structural decisions.
- `docs/README.md` — source map and canon hierarchy.

Major creative decisions should be recorded rather than silently changing canon.

## Narrative form

The working novel form is a **recurring first-person ensemble**. Chapters are named for their POV character. Characters return non-mechanically across the book, and chapters may overlap in story time when a new perspective materially changes the reader's understanding.

See `docs/narrative-structure.md` and `docs/timeline.md`.

## Repository structure

- `chapters/` — manuscript drafts and prototypes.
- `docs/` — canon, continuity, architecture, research, theology, style, and decision records.
- `agents/` — individual writing-team role cards.
- `workflows/` — architecture, drafting, review, and continuity workflows.
