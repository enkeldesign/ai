# Revelation AI

A hard-SF / techno-theological novel project set in 2027.

The story mirrors the structure and symbolic logic of the Book of Revelation while grounding each event in plausible AI, climate, infrastructure, persuasion, and social-system mechanisms.

## Canon

The fixed premise lives in `docs/premise.md`. Major creative decisions should be recorded in `docs/decisions-log.md` rather than silently changing canon.

## Repository structure

- `chapters/` — manuscript drafts
- `docs/` — canon, lore, research synthesis, theology, and decision records
- `agents/` — roles and handoff expectations for AI collaborators
- `workflows/` — drafting, review, research, and continuity workflows
