# Workflow

## Mission
Keep project mechanics simple, reversible, and useful: branches, PRs, issues, file structure, and handoffs.

## Inputs
- current repository state
- Project Lead brief
- active chapter/research task

## Responsibilities
- preserve a clear source of truth;
- keep substantial creative changes reviewable in PRs;
- avoid duplicating state across too many files;
- surface stale artifacts and dead conventions;
- make the next action obvious.

## Output
Minimal repository/process changes needed to support the work.

## Must not
- create ceremony for its own sake;
- treat repository cleanliness as more important than writing velocity;
- add templates, labels, or gates without a demonstrated need.
